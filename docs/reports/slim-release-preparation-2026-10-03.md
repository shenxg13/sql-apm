## 目标机试跑方案与未完成项

程序和操作手册已准备；用户明确确认并恢复初始快照、确认虚拟磁盘仍位于 SSD 后，才开始：

1. 传输完整离线包与外部摘要并逐项校验，按 HTML 手册准备系统包。
2. 在项目目录重新编译 Python 3.9.5 和 PG17.10，部署精简程序、离线依赖及独立验收资源。
3. 执行环境自检、数据库初始化和受限 TCP 正误密码验证，校验 55 个源日志并生成配置。
4. 在干净数据库上用四个解析进程运行 119 首批，记录超时计数、正式分组、Alma 等值、版本链和资源。
5. 如有超时或计数差异，先保留记录及失败现场，再按手册重置后以单进程重跑首批；
   产品问题经用户确认另开 Issue。本次不修复产品默认并发或 5 秒期限，不预判磁盘为原因。

用户之后再恢复一次快照，使用单进程九任务手册独立执行；yum 源路径及随后两项编译、
HTML 断网浏览器阅读／跳转／复制／搜索／打印仍需用户记录。候选包的目标机重走、
四进程结论和这些人工结果尚未发生，不将旧包证据或开发机自动检查计作完成。

打标签和发布为合并后的 K16，并需另行用户确认；完整离线包和验收材料不上传 Release。
