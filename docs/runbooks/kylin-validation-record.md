# Kylin v0.2.0 验证记录模板

本模板用于实施方一次裸机演练和实测后的用户 HTML 检查。复制到仓库外或本地忽略目录，
按[手册](kylin-offline-deployment.md)填写。原文、真实主机地址、账号及凭据不进入公开记录；
公开机器记录只含计数、标识、月份、时间、大小、摘要和固定原因码。失败输出也必须保留。

## 结论与证据继承

- 观察：系统事实及直接输出。
- 验证：已通过的命令、机器记录及其摘要；性能与资源为 measured，不设门槛。
- 推断：容量估计等单列，不伪装成实测。
- 未验证：生产、120 三十天首批、其他系统／架构／主机／并发、目标机真实带数据升级。
- 最终候选产品文件与实测包逐项摘要一致；文档／验收资源差异及受影响步骤补验记录。
- 用户文档确认及修正记录；独立评审、合并后发布另行跟踪。
