# sqlfind 使用说明

`sqlfind` 是给 MPP 运维人员使用的中文终端检索工具，随 v1.1.0 程序包交付。
先由 `sfmon` 按[生产安装手册](production-installation.md#11-sqlfind-一次性配置)配置只读连接，重新登录后可在任意目录使用。
它只查询已导入的日志和已发布的基线，不执行输入的 SQL，不把 SQL 或结果写入本地历史文件。

## 一、一次输出

给出检索内容时输出一次并退出；先看候选，再用本次列表中的标记选一项：

```bash
sqlfind --help
sqlfind 'select'
sqlfind 'select' --show 1
sqlfind 'select' --show 1 --limit 5
sqlfind 'select' --show 1 --view originals --original all
sqlfind 'select' --show 1 --original 1 --view text
sqlfind 'select' --show 1 --view history --limit 100 --history-order slowest
```

后五条以存在候选 `1` 为前提，单份原文的编号也须先核对原文列表。没有命中不是故障。
每次命令都会重新检索，数据变化可能改变编号；需要固定结构时可直接输入完整结构指纹。
省略 `--show` 只显示候选；省略 `--view` 显示整页详情。

输入来源三选一：命令行内容、`--file` 指向的 UTF-8 文件、标准输入。
文件和标准输入保留首尾空白及换行。以下为可以直接执行的合成示例，不要求数据库里存在对应 SQL：

```bash
printf '%s\n' 'select' | sqlfind
sqlfind --mode passage 'from example_table'
sqlfind --mode exact <<'SQL'
SELECT id, name
FROM example_table WHERE status = 'ready';
SQL
```

示例可能没有命中，正常完成仍退出 0。不要把含业务数据的 SQL 放进公开报告；
敏感输入优先用交互、文件或标准输入，避免进入 shell 命令历史。

## 二、交互使用

不带检索内容且输入、输出都是终端时进入交互：

```bash
sqlfind
sqlfind --mode exact
```

第一条先选择方式，第二条直接输入完整 SQL，退出前一会话后再执行下一条。
按词输入一行后回车；整段或完整 SQL 粘贴结束后再按一次回车、Ctrl-D。
选择方式、候选列表和详情菜单输入 `?` 查看对应帮助；检索内容里的 `?` 仍按原文处理。

| 位置 | 命令 | 用途 |
| --- | --- | --- |
| 候选列表 | `1` 等当前标记 | 打开对应结构的详情；逐条提示可能用 `s1` 等标记 |
| 候选列表 | `o`、`l` | 调整候选排序、重看列表 |
| 详情 | `i 序号`、`t 类别` | 选择身份组合或计时类别，按当前可用列表输入 |
| 详情 | `v` | 查看当前原文范围的目录 |
| 详情 | `v 编号` | 选择一份原文，查看它的执行历史 |
| 详情 | `v matched`、`v all` | 选择本次命中原文、整个结构的全部原文 |
| 详情 | `f` | 单独显示完整原文；集合范围显示一份示例 |
| 详情 | `h` | 设置历史条数、时间范围和最新／最慢排序 |
| 详情 | `b` | 返回候选列表 |
| 列表或详情 | `n`、`q` | 新检索、退出 |

Ctrl-C 取消当前步骤或查询；菜单中按提示继续或退出。`h`／`o` 向导回车保留、`q` 或 Ctrl-C 取消；
`h` 中 `r` 恢复默认历史设置。有效设置在当前会话后续检索中保留，退出后不保存。
退格可以删除中文和普通字符；方向键目前忽略，不移动光标或调取历史。
输出带操作编号与起止标记，便于滚轮回看；没有清屏或分页，原文不会被程序强制折行。

## 三、三种检索方式

| 方式 | 参数 | 匹配规则 |
| --- | --- | --- |
| 按词 | `--mode words`（默认） | 每个词都出现，最多 20 词 |
| 整段 | `--mode passage` | 连续片段匹配，适合从原文复制的一段 |
| 完整 SQL | `--mode exact` | 按可靠结构指纹匹配；可输入完整结构指纹固定结构 |

完整 SQL 的多语句输入会给出整体结果及必要的逐条提示；无法生成可靠指纹会明确说明，
不自动降级成模糊检索。结果只覆盖已导入的数据，不能证明生产上从未执行过。

## 四、候选和详情怎么读

候选先显示本次检索、筛选、排序、结构总数与实际显示行数；默认按记录数最多排序，最多显示 50 个结构。
候选中的原文数、记录数与预览帮助选择结构，进入详情后再核对完整指纹和身份。
80 列窗口会用续行保持表格可读，较宽窗口可将每个候选显示为一行。

详情依次给出完整指纹、原文、可用身份、当前基线和执行历史。身份是集群、数据库、执行用户的组合，
计时类别另选；与看板比较时须使用相同身份、计时和当前版本。样本不足会明确提示，不能把不足的数值当作可靠阈值。
原文或历史时间选择只影响显示的原文与执行历史，不改变当前结构基线及其训练窗口。

原文列表区分“本次命中多少份”和“当前身份、计时、时间内出现多少份”，当前范围记录数为 0 的原文也可能在目录里。
目录列出编号、记录数、最近执行和原文不同部分；共同开头与结尾省略，长差异的中间省略有明确标记。
执行历史里的原文编号对应此目录。`f` 或 `--view text` 看全文，`--full-text` 只取消整页详情中默认 4000 字符的截断。
原文保留制表符、LF 和 CR LF，其余终端控制字符显示为可见转义，并在原文外说明；数据库原文没有改动。

历史默认从所选身份最近一次执行往前 7 天取最新 20 条，条数允许 1–1000；显示范围内总数与实际条数。
最慢排序针对整个所选范围，不是仅重排当前显示的几条。时间未写时区时按北京时间，包含开始、不包含结束。
没有记录时显示 0 条，基线仍可能存在。

## 五、常用参数

| 参数 | 作用 |
| --- | --- |
| `--cluster`、`--database`、`--user` | 筛选日志里的集群、数据库、执行用户；不是修改登录账号 |
| `--start`、`--end` | 筛选候选的时间范围，不设置详情历史时间 |
| `--order count` 或 `recent` | 候选按记录数最多或最近执行排序 |
| `--show`、`--identity`、`--timing` | 选择候选、身份序号及计时类别；后两者须与 `--show` 一起使用 |
| `--limit` | 历史条数，1–1000，默认 20 |
| `--history-start`、`--history-end` | 必须成对提供的历史时间范围，省略时为默认 7 天 |
| `--history-order latest` 或 `slowest` | 历史按最新或最慢排序 |
| `--original matched`、`all` 或编号 | 本次命中、全部或指定原文；须先核对本次编号 |
| `--view detail`、`originals`、`history`、`text` | 整页详情、原文目录、仅历史、仅全文 |
| `--full-text` | 整页详情中的原文不截断，不能与 `originals`／`history` 同用 |
| `--width` | 重定向输出宽度，默认 100、最小 20；终端随窗口宽度 |

完整参数看 `sqlfind --help`。`--limit`、历史参数、原文参数和视图参数均为一次输出时的详情选项，须与 `--show` 一起使用；
交互中通过菜单设置。按词／整段默认选命中集合，完整 SQL 有一字不差的原文时选该份，否则选全部；按指纹查找时选全部。

## 六、PuTTY 设置

Window → Translation → Remote character set 选择 **UTF-8**，服务器使用 UTF-8 locale。
先用 **80 列 × 24 行**，也可以最大化；内容用滚轮回看，回滚不足时在 Window 增加 scrollback 行数。
不需要全屏终端或额外分页器。粘贴长 SQL 后按上述回车、Ctrl-D 完成输入；Ctrl-C 可取消。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 `sqlfind` | 先由当前登录账号完成一次性配置，再重新登录；核对程序目录仍存在 |
| 提示未配置连接 | 按生产手册配置；不把密码写进命令或连接串 |
| 连接失败 | 核对 socket、端口、只读角色、密码文件权限与数据库服务；已有 `SQL_APM_DSN`、`PGPASSFILE` 会优先覆盖配置 |
| 查询超时 | 只读账号默认单条查询超时 120 秒；缩小筛选范围后重试，保留脱敏症状反馈 |
| 参数、日期或编号无效 | 查看帮助，核对本次列表；交互可继续输入，编号不保证跨检索稳定 |
| 没有结果或无法生成可靠指纹 | 查看提示，核对方式、筛选和最新导入日期；这两类正常返回不代表程序故障 |
| 中文乱码或替代字符 | 核对 PuTTY 与服务器 UTF-8；不能表示的字符会提示并替代显示 |

一次输出查询成功（含无命中、无法生成可靠指纹）退出 0，参数／输入／连接／查询错误退出 1；交互正常退出 0。
全量数据上的详情和原文目录耗时尚未验证；部分样本的测量只适用于该批数据，结果见[发布说明](../releases/v1.1.0.md)。
