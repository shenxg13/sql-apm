## 来源范围与目录审查

固定 PostgreSQL 9.4.26 官方源码中的 `func.sgml`、`pg_proc.h`、`pg_type.h`、
`system_views.sql`；各文件 SHA-256 和逐签名来源位置保存在
[来源清单](../../rules/functions/postgres-9.4.26-inventory.json)。
重新运行导入器所得清单与提交清单逐字节相同。

| 口径 | 数量及处置 |
| --- | --- |
| 初始目录及 SQL 安装签名事实 | 2,580 |
| 第 9 章表格／函数引用涉及的名称 | 409 |
| 这些名称展开后的签名 | 775；均有明确审查结论 |
| 至少一个参数允许归一化 | 176 |
| 审查后明确保留全部参数 | 599 |
| 目录中不在上述文档范围的签名 | 1,805；只保留来源事实，未计已审查 |
| 文档签名引用条目 | 559；同一名称可能在不同类别重复出现 |
| 文档边界处置 | 27 个特殊语法名称、2 个表格片段、5 个其他系统／历史引用 |
| Greenplum v6 扩展 | 4 条明确保留、5 条 pending |

审查覆盖率的分母是上述 775 个文档相关签名；不是全部 pg_proc、所有 PostgreSQL
扩展或 HashData 现场函数。保留结论是本项目按语义类别作出的首版策略选择，
不表示这些参数在所有未来场景都不可归一化。源码事实与本项目策略分别保存。

[自动覆盖结果](function-dictionary-coverage-2026-09-25.json)逐类别记录计数及待核实条目。
[Greenplum v6 官方资料](https://docs-cn.greenplum.org/v6/ref_guide/gp_toolkit.html)
为扩展用途提供依据；未取得现场目录，不宣称验证 HashData 3.13.13 同名函数。
其他 6.x 或 7.x 新增函数不能自动归入当前 6.20.3 范围。

## 本地日志有界核对

每个集群按文件名排序取前两个文件，每文件最多 2,000 条 CSV 逻辑记录、
8 MiB 读取预算，另设单物理行及字段 1 MiB 上限。输入校验背景见
[原日志分析](cluster-log-analysis-2026-09-24.md)。抽样不依赖默认 30 日训练窗口。
读取 CSV 第 25 列 SQL 字段，不筛选为真实业务完成执行；不同阶段或重复文本均可能出现。

| 集群 | CSV 记录 | 含 SQL 记录 | 词法可读取记录 | 调用候选 | 命中 normalize | 命中 preserve |
| --- | --- | --- | --- | --- | --- | --- |
| 119 | 4,000 | 3,445 | 3,161 | 8,765 | 300 | 875 |
| 120 | 4,000 | 3,765 | 3,369 | 7,128 | 3,080 | 322 |

词法候选命中比例分别为 13.41% 和 47.73%，仅是本次无类型信息探测的指标。
其分母含未匹配候选，不删除歧义／未知函数来抬高命中率；不是已解析函数调用率、
生产全量覆盖率、执行数或最终指纹归并率。部分表名或类型形式也可能仍是候选误报。

119 有 284 条、120 有 396 条含 SQL 记录因 DDL／过程语法、括号或引号问题等
没有进行调用候选统计。另有 8,123／7,107 个特殊语法或不确定位置单列，
它们没有可靠函数身份，不被伪装成已命中调用。详细原因、逐文件读取前缀 SHA-256、
已读取字节数、逻辑记录和人工回放定位见[脱敏抽样结果](function-dictionary-sample-2026-09-25.json)。
报告不含生产 SQL、函数／schema 业务身份或绑定值；未知身份通过本地来源定位复查。

无类型信息时，lower、length 等标量／结构化重载可能产生不同动作，必须报告
ambiguous_overload。聚合／窗口需要真实语法上下文，可变参数需要解析器，均单列。
不能根据这次词法命中比例承诺主引擎接入后的合并收益。

同一有界抽样重跑两次，脱敏输出逐字节相同；文件读取前后大小和 mtime 保持一致。
前缀校验是本次读入字节的校验，未为本任务重新扫描或重算整个生产文件摘要。

```bash
.venv/bin/python scripts/functions/sample_logs.py --root raw/inbox/hashdata \
  --output /tmp/sql-apm-function-sample.json
```

读取预算触发时可能多读 1 字节用于确认越界，此字节计入证据摘要；停止原因单列。
本次四个文件均先到逻辑记录上限。

## 产品验证

- 字典加载与摘要验证通过；规则版本及当前摘要保存在自动覆盖结果。
- 17 个 unittest 测试方法通过，其中逐条检查 775 个文档重载的选择可达性。

## 限制与后续接入

现场扩展及自定义函数目录仍缺失；在没有类型解析和会话还原时，选择结果以已声明
的上游假设为限。字典快照、版本、摘要与主引擎接入约定见
[维护说明](../../rules/functions/README.md)。

性能证据为 qualitative：本地静态数据和内存索引，无数据库、常驻服务或生产 SQL
执行；未进行热路径性能基准。日志读取最多四个小前缀，不扫描全部生产数据。
字典、策略预览和词法候选检测不组成完整 SQL 解析器或指纹主引擎。
