# SQL APM v0.2.0 预发布

这是离线 SQL 基线程序的 v0.2.0 预发布，**不用于生产**。应用版本与数据库结构版本不同：
本包使用结构 1.9.0。完整裸机安装还需要内网交付的依赖与验收包。

## 相对 v0.1.0 的变化

- #34 修复分词位置换算的性能问题，保持 5 秒归一化期限和默认四解析进程。
- #33 将产品技术标识统一为 MPP，规则上下文和分组标识随之改变。
- #35 在 full／rebuild 中按训练窗口起点选完整批次，输出完成、入选、排除及回退情况。
- #43 提供结果保留月数、只读清理预览和显式按月清理；当前版本的整个月份受保护。
- 随包新增配置指南、数据库结构说明和本入口页；独立验收包新增合成清理入口。

## 数据库兼容性

v0.1.0 的结构为 1.6.0，必须重建数据库，不能带数据升级到本包的标识上下文。
1.7.0／1.8.0 可升级至 1.9.0；带真实数据升级只在开发机验证，Kylin 仅执行合成升级检查。
后续 0.x 预发布之间仍不承诺数据库兼容。

## 验证范围与结果

已在 Kylin V10 SP2 x86_64 演练机（8 vCPU、14 GiB 内存）从初始状态完成本轮实测：

- 离线 RPM 安装、Python 3.9.5 与 PostgreSQL 17.10 源码构建、新建结构 1.9.0 数据库、
  密码连接及启停通过。随包 unit 72 项、database 276 项、publication 33 项、smoke 和 cleanup 23 项通过。
- 119 五项与 120 四项任务全部成功发布；八次导入均使用默认四解析进程，归一化超时和 OOM 均为 0，
  业务计数与选批字段逐项匹配基准。九任务 CLI 合计 6672.201 秒，结束时数据库 56347047603 字节。
- 训练窗口、样本门槛、模板排除和时段排除四个示例均重建并通过开发机比较；同机门槛前后的全部
  统计值精确不变。跨机仅两列对数统计允许逐行绝对差不超过 1e-12，实测最大差为 1e-15，其他字段及 NULL 状态一致。
- 自然日期清理没有删除结果，预览审计及全部结果不变。最后暂停时间同步并模拟 2027-01，验证旧月份
  保护、两个集群各重建一次、12 个月保留与默认 2 个月过期，再实际清理旧月份。共释放统计分区
  16852598784 字节；旧分区与分组关联无残留，历史版本标为已清理，当前版本全部结果精确不变，结构检查通过。

结果对应本轮固定候选；仅文档更新后的交付候选以全部 76 个产品文件路径和摘要相同继承证据。
任务内存为每 250ms 采样的主机 MemTotal−MemAvailable，峰值 14254317568 字节；
该值包括操作系统和数据库，主机有 swap 占用，不能解释为解析进程 RSS 或生产资源预算。

## 已知限制

本版不验证 120 三十天首批、生产内网 yum 源、其他初始系统的 RPM 完整性、aarch64、
其他并发数或其他主机；不在目标机用真实数据验证带数据升级。不配置每日自动任务、
定时清理或连接存活参数。不提供 SQL 检索、Grafana 展示、生产日常运行手册或项目许可证选择。

清理演练最后使用模拟系统日期；该机在恢复快照前不再用于其他验收。
实测资源记录不构成生产性能承诺。
