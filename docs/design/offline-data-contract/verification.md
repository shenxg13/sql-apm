## 人工语义走查

- A1／A2：三个交接边界有生产者／消费者及字段定义；基础实例从来源到生效指针的
  引用可解析。源列、人工映射、推导和未知分别表达，来源时区和构建范围有明确依据。
- A3：E02–E16 核对原文复用、不同执行、混合／纯黑名单批次和六个日志分支至五类计时；
  Execute 配对两条证据只计一次调用，未配对不归首次／续取，Parse／Bind 不冒充请求。
- A4：E21、E28–E40、E59 及 N07／N11／N12 核对五层键、窗口首尾、独立覆盖、
  全部指标、零／单样本及零分母。基础实例开始 08:59:59.990，因此小时键确为 8。
- A5：E03–E04、E13–E27、E58、E61–E63 及 N01／N06 核对合法不完整输入、
  失败／取消／超时、维护区间、多重排除、未知状态、未排除 DDL 与成功长耗时。
  无 SQL／时间归属的问题留在批次层，原因数之和不要求等于去重排除总数。
- A6：E41–E55 及 N07–N10／N13 核对同源重复、安全重试、可靠冲突、损坏文件、
  完整性与一致性、全部不足、仅调用有样本、五类均空、保存／发布失败、无旧版和忙时拒绝。
- A7／A8：E53–E57 核对原始事实、解释、规则、构建及当前指针的引用；旧统计不被重写，
  合成跑批对象不伪造 SQL 或继承 HashData 分组／门槛，不代表新增适配器承诺。
- A9：函数规则沿用已交付 1.0.1 的选择及摘要语义；类别规则沿用七项和保守边界。
  本目录没有生产 SQL、生产身份、原始日志包或现场执行结果。导航、契约主题和知识日志同步。
