# Project Operating Model Template

Copy this decision template into the project's decisions directory, complete the
fields, obtain confirmation and link it from the wiki index and task catalog.

## Summary

Describe maintainers, operators, consumers and deployment environments.

## Source Of Truth

Link the confirming decision and relevant implemented boundaries.

## Contracts

Record in-scope threats, out-of-scope threats, authority delegated to automation,
secret ownership and meaningful performance/recovery requirements.

## Workflows

Describe how requirements, implementation and review apply this model.

## Failure Modes

Describe material mismatches between the declared model and actual operation.

## Update Rules

State when ownership, exposure, authority or incidents require re-evaluation.

## Open Questions

List unresolved choices. A draft template is not an accepted operating model.
