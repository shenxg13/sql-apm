## 相对 v1.0.0 的变化

- 将 #62 的中文命令行检索 `sqlfind` 和只读账号配置工具加入程序包，提供独立使用说明。
- 将 #65 的 MPP 端推送模板、SQL APM 收取工具与配置示例加入交付；生产手册以推送接入为主，拉取步骤移至附录。
- 验收包增加 sqlfind 数据库／终端和推送／收取检查；二进制自检增加 sqlfind 入口。
- 沿用 v1.0.0 唯一 Kylin 成品：Python 3.13.16、虚拟环境和 PostgreSQL 17.10，
  `runtime.tar.gz` SHA-256 为 `d271d6a1471c41723724b48afad59f9675e1b324747fbb7dfae283f97340314c`。
  不重新编译，源码、wheel、RPM、Grafana 和三个插件保持相同，见[原编译记录](../reports/v100-runtime-build-2026-10-12.md)。
- 导入、构建、检索、看板、每日运行等产品行为沿用已合并实现；不包含 #61“运行中的 SQL”。

**每日运行默认自动清理过期版本结果，并删除到期原始日志。** 默认结果保留 2 个月、原始文件 45 天；
分别用 `cleanup.enabled=false`、`raw_files.retention_days="off"` 关闭。

## 已验证

本版开发机验证见[准备报告](../reports/v110-preparation-2026-10-16.md)，仅在相应机器记录通过后计入。
v1.0.0 的运行时编译与目标机结论保留在原报告中，不直接算作本版通过。

本版仍须完成：演练机初始快照上的全新安装；跨机器推送 → 收取 → 每日运行；sqlfind 及与看板核对；
部分样本上 O-62-005 的详情与 `v` 中位耗时；PuTTY 用户验收和重写手册的平台步骤核对。
完成后按机器记录更新本节，当前不声称这些步骤已验证。

## 未验证

- 全量数据上 sqlfind 的详情和原文目录耗时；部分样本测量不能外推到全量或生产。
- 真实备份平台推送到真实 SQL APM 服务器，真实 master 的执行环境及目录。
- 真实生产机安装、生产上 PuTTY 的版本与设置。
- 120 三十天首批的成本；32 GB PostgreSQL 参数建议值。
- 拉取和编译路径在本版没有重新做目标机验证；开发机拉取回归单独记录，不作为真实 master 验证。

## 不提供

本版不提供带数据升级的手册、脚本或演练，只支持全新安装，不能从 v1.0.0 原地升级。
本版不提供 PostgreSQL 数据库备份和恢复，由部署方自行安排；原始日志默认只保留 45 天，
数据库损坏后更早的执行历史可能无法重建。项目许可证继续搁置。

## 组件维护

Grafana 13.2.3、Business Forms 6.3.5、Infinity 4.1.1、PostgreSQL 数据源 13.0.4 的固定摘要沿用 v1.0.0。
Grafana 13.2 系列官方支持截止 **2027-05-18**，见[官方支持表](https://grafana.com/docs/grafana/latest/upgrade-guide/when-to-upgrade/)
（沿用 v1.0.0 于 2026-10-12 的核对记录）。保持密码认证、插件签名和关闭启动自动下载；HTTPS 仍可选，默认 HTTP。
离线环境通过后续产品版本更新组件；v1.0.0 及更早标签与附件保持原样。
