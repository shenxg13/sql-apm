# v1.1.0 开发机准备记录

范围见 [Issue #67](https://github.com/shenxg13/sql-apm/issues/67)。用户要求先完成不需要验证机的部分。
本记录只描述开发机准备与实测；目标机、用户验收仍待完成，v1.1.0 尚未正式发布。

## 实现

- 程序包增加 `bin/sqlfind` 和账号配置工具，保留启动入口及推送／收取脚本的执行权限。
- 验收包增加 sqlfind 数据库／终端和推送链路入口；测试从显式选择的 app 加载产品，支持独立解包。
- 自检增加 sqlfind，普通测试由 113 更新为包含 #65 用例的 131 项；收取与推送测试也使用指定 app。
- 生产手册改为推送接入，原第 8 节拉取正文与基线逐字核对相同，仅移入附录；sqlfind 有一次性配置与撤销。
- 新增 SQLFIND.html，与其余六份 HTML 一起交付；发布说明同源生成包内 HTML 和带提交链接的 release-notes.md。
- 运行时和依赖固定复用 v1.0.0；相对基线，sql_apm、daily、bin、数据库结构、规则及配置工具的产品代码均未改变。

## 开发机检查（measured）

本机为 Python 3.13.16、PostgreSQL 17.10；构建环境使用锁定的 Python-Markdown 3.8.2。
输出、退出码、输出摘要在 `var/issue67/checks/`，这些目录被 Git 忽略。
`development.json` 记录源码检查，`isolated.json` 记录解包检查；原始失败输出保留，不覆盖成通过。

当前发版合成套件均已通过；最终交付身份与接续状态由在线 PR 记录。

变化只涉及交付、文档与验证适配；不进入导入、分组、查询或每日运行的业务热路径。
