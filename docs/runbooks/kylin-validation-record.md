# Kylin v0.3.0 验证记录模板

实施方演练、用户手动全流程验收各复制一份到本地忽略目录，分别填写，不合并两轮结果。
两轮都先由用户恢复初始快照，再由实施方保存传输前只读探测；第二轮实际操作由用户完成。
按[安装手册](kylin-offline-deployment.md)逐步记录，密码、原文、真实地址和账号只留受保护的本地文件。
失败也保留原始输出与退出码，修正后填写补验结果，不覆盖失败记录。

## 结论与补验

- 观察：系统事实与直接输出；验证：检查结果及其摘要；推断：容量估计等，分开记录。
- 问题：编号、步骤、实际结果、修正提交、影响范围、补验步骤与结果。
- 用户手动完整流程确认：未确认／通过／未通过，日期与用户原话链接。
- 证据一致：两轮与最终候选产品文件逐项相同；文档／验收资源差异及补验单独列出。
- 未完成项：据实列出；独立评审、合并后精确制品确认及发布分别跟踪。
